## 問題與解法摘要 (Elevator Pitch)

**痛點 (Problem)：**
台灣即將邁入超高齡社會，醫療需求極大。然而，現有醫院的數位掛號系統介面複雜、字體小、步驟繁瑣，導致長者無法獨立操作，只能極度依賴家屬代勞或親赴現場排隊，加深了數位醫療落差；一旦長輩操作卡關，家屬往往人不在現場，無法即時協助。

如同我們整理的視覺化儀表板，揭示多數長者面臨使用數位醫療服務的挑戰；因此，本程式設計希望讓 AI 成為長者與數位醫療系統之間的「翻譯者」與「代理人」，並讓照顧者能在長輩需要時被即時「拉進來」，而不是等出事才知道。

👉 **[點此觀看：高齡化社會與醫療數位落差 視覺化儀表板](https://cool-bush-b2e3.anchieh2.workers.dev)**


**解法 (Solution)：**
「安心掛號」是一款專為長輩打造的語音掛號 Web App，定位是「高齡者健康照護數位助手」——不只是幫忙掛號，而是陪長輩走完「就醫前 → 掛號中 → 看診後」整段流程，並在需要時把照顧者接進來。相較於傳統的下拉式選單與複雜表單，我們改以：
1. **一鍵語音說話** 作為主要輸入方式，且支援用「症狀描述」（例如「眼睛很癢看不清楚」）或「回診／初診」等口語，不需要長輩自己講出正確科別名稱。
2. 結合 **AI 意圖識別**，自動判斷科別、看診類型（初診／複診）與時間——僅作為掛號科別的判斷輔助，不是醫療診斷。
3. 導入 **家屬接力** 機制：長輩用說的，最後確認交給家屬；若長輩操作卡關（語音多次辨識失敗），可一鍵請家人協助，系統會主動把「卡在哪一步」整理好推播給家人。
4. 看診前後提供 **簡化提醒卡片**：報到時間、應攜帶證件、看診後注意事項，方便長輩與家屬一起掌握。
> **注意：本專案僅為 Hackathon 展示用，不登入真實醫院系統、不接觸真實病患資料，也不會自動送出任何真實掛號。**

## 核心特色與已完成功能

**「安心助理」首頁 — 三個入口，對應三條 Demo 流程：** 首頁不再直接進入掛號流程，而是先問「今天需要什麼幫忙？」，中間是大顆的按住說話麥克風，下面是三個入口：🏥 醫院掛號（下方的語音掛號流程）、📷 看不懂這個（拍照/文件理解，見下）、👨‍👩‍👧 請家人幫忙（見下）。長輩找不到「掛號」兩個字也沒關係，說出需求或點入口都可以。

**看不懂這個（文件理解，輕量示範版）：** 長輩對著看不懂的通知單「開啟相機」或「從照片選擇」，AI 立刻整理成「回診日期／時間／地點」三行重點，並提供「加入提醒」或「我還是不懂」；選「我還是不懂」會直接請家人看看。目前為情境劇本示範（固定範例文件），尚未串接真正的圖片辨識 API。

**請家人幫忙（AI 不確定才升級）：** 不是「隨時都能求助」的按鈕，而是模擬「AI 判斷自己無法安全處理時才建議請家人」的情境：一鍵把目前狀況整理成訊息透過 LINE 推播給家人，並顯示「家人端會看到的畫面」預覽，讓長輩不用重新解釋一次。

**長輩友善語音介面：** 按住說話的錄音介面，自動串接 OpenAI 語音轉文字（未設定金鑰時會自動降級使用瀏覽器內建語音辨識）。

**就醫前 AI 導引（症狀 → 科別）：** 長輩不需要知道正確的科別名稱，只要描述症狀（例如「眼睛紅腫癢」「我要回診」），AI 會判斷最可能的科別與看診類型（初診／複診／未確定），並在畫面上清楚標示「這是掛號科別建議，不是醫療診斷」。無 API Key 時，具備本地關鍵字規則解析備援，功能一樣可以運作。

**真實醫院班表資料：** 讀取長庚醫院公開掛號頁面的真實班表（唯讀爬蟲，非官方 API），抓取失敗時自動重試，全部失敗才會清楚標示退回穩定示範資料，畫面永遠不會白屏或報錯。

**安全與防呆機制：** 支援台灣身分證基本格式校驗（`^[A-Z][0-9]{9}$`），資料只留在裝置端記憶體，不上傳、不寫入資料庫；「最後確認送出」保留給本人或家屬，絕不自動送出掛號、絕不繞過驗證碼。

**家人/照顧者協助模式：** 當長輩多次語音辨識失敗、卡在確認步驟時，畫面會出現「改請家人協助」按鈕，一鍵把目前卡住的內容（原始語音文字）整理成訊息，透過 LINE 推播給家人，讓家人能立刻知道長輩卡在哪、需要什麼協助。

**家屬接力掛號：** 透過 LINE Messaging API 自動推播掛號摘要，支援**同時通知多位家人**（以逗號分隔多組 LINE 使用者代碼），沒有設定自動通知時則退回 LINE 官方分享連結；掛號摘要不含身分證等敏感資訊。

**看診後提醒與簡化資訊：** 完成掛號流程後，提供一張簡化的看診提醒卡片（報到時間、應攜帶證件、如需改期的提醒），並可透過既有的 LINE / 分享機制傳給家人，方便共同掌握看診安排。

**語音唸出來（TTS）：** 「我聽到的是這樣」與最後總結兩個畫面各有一顆「🔊 唸給我聽」按鈕，用瀏覽器內建的語音合成把確認內容唸給長輩聽，不需要額外金鑰或費用，視力不好也能靠聽的確認。

**放大文字模式：** 頁首「Aa 放大文字」按鈕一鍵把全站文字與按鈕再放大一階，並記住這個裝置的偏好，下次打開自動套用。

**用藥提醒與回診提醒（選填）：** 在最後總結畫面可以填一句用藥提醒（例如「早晚各一次，白色血壓藥」），或選擇「幾週後回診」，系統會把這些提醒直接整合進傳給家人的 LINE 訊息裡；目前是輕量版，提醒內容會隨掛號摘要一起送出，但不會在時間到了另外自動跳出通知，仍需要家人幫忙留意日期。


## 本機執行方式 (Local Setup)
本專案提供非常簡單的本機執行方式，即使沒有 AI 金鑰也能透過瀏覽器備援功能運行。

### 1. 系統需求
**Node.js** 22.13 或以上版本。

### 2. 安裝與啟動步驟
請在終端機中依序執行以下指令：
```bash
# 1. 安裝依賴套件
npm install

# 2. 複製環境變數設定檔
cp .env.example .env.local

# 3. 啟動開發伺服器
npm run dev
```

啟動後，請打開瀏覽器前往：http://localhost:3000。
 (若需建立正式上線版本，請執行 npm run build)

### 3. 環境變數設定 (選用)

打開剛剛複製的 .env.local 檔案，您可以填入 OpenAI 金鑰以啟用進階的 AI 語音與解析功能：

```
OPENAI_API_KEY=您的_OPENAI_API_金鑰
TRANSCRIPTION_MODEL=whisper-1
INTENT_MODEL=gpt-4o-mini
LINE_CHANNEL_ACCESS_TOKEN=您的_LINE_CHANNEL_ACCESS_TOKEN
LINE_CHANNEL_SECRET=您的_LINE_CHANNEL_SECRET
LINE_FAMILY_USER_ID=家人的_LINE_userId（可用逗號分隔多位家人）
```

註：為了隱私與安全，金鑰僅放於本機或部署平台的 Secret 中，絕不會提交至 Git。所有語音錄音皆為即時處理，絕不寫入檔案或資料庫。

## 系統架構與素材來源說明

為了證明本專案的落地可行性與資料真實性，本專案的數據與素材來源皆為公開且具公信力之資料：

### 1. 醫療與數據來源

• 高齡化與數位落差儀表板數據取自國家發展委員會《中華民國人口推估報告》、TWNIC《台灣網路報告》及健保署統計年報。

• 醫院掛號系統對接為唯讀爬蟲，即時讀取長庚醫院（台北長庚．眼科等科別）公開網路掛號頁面的真實班表；抓取失敗時自動重試，全部失敗才會退回並清楚標示為穩定示範資料，確保畫面永遠不會壞、也不會誤導使用者。

• 系統從不登入醫院內部系統、不觸碰病患資料庫，也不會代為完成最終送出掛號的動作。


### 2. 技術與開源工具

• **語音與 AI：** OpenAI 語音轉文字 API + OpenAI 語言模型（結構化 JSON Schema 輸出），將自然語言精準解析成「意圖 / 科別 / 看診類型 / 日期」；無金鑰時具備本地規則解析備援。

• **前端與框架：** vinext（類 Next.js 框架）+ React + TypeScript，部署於 Cloudflare Workers，具備響應式設計以支援長者手機大字體顯示。

• **家屬協作：** LINE Messaging API（Webhook 簽章驗證 + Push API），支援同時通知多位家人。
