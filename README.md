# 🏥 安心掛號 (Anxin Registration) Demo
> 長輩友善的醫院掛號流程展示。介面以大字、少量選項、語音輸入與家屬交棒為核心。

> ⚠️ **注意：本專案僅為 Hackathon 展示用，不登入真實醫院系統、不接觸真實病患資料，也不會自動送出任何真實掛號。**

🌐 **線上 Live Demo：** [點此體驗安心掛號](https://anxin-registration-demo.modest-loon-8360.chatgpt.site)

 
## 📊 專案設計背景：高齡化與數位醫療落差
本程式的設計初衷與重要性，是建立在對高齡者醫療需求與數位落差的深刻洞察之上。我們發現長者雖然是醫療服務的重度使用者，但現有數位工具的門檻往往將他們拒之門外。
為了讓大家更了解本設計的重要性，我們整理了一份視覺化儀表板，揭示台灣快速邁入高齡社會的現況。本程式的設計正是希望讓 AI 成為長者與數位醫療系統之間的「翻譯者」與「代理人」。

👉 **[點此觀看：高齡化社會與醫療數位落差 視覺化儀表板](https://cool-bush-b2e3.anchieh2.workers.dev)**


## ✨ 核心特色與已完成功能
🎙️ **長輩友善語音介面：** 按住說話的錄音介面，自動串接 Whisper 語音轉文字（未設定金鑰時會自動降級使用瀏覽器內建語音辨識）。

🧠 **AI 意圖解析：** 透過 LLM 解析語音，精準提取 `intent (意圖) / department (科別) / date (日期)`，並具備無 API Key 時的本地規則解析備援。

🛡️ **安全與防呆機制：** 支援台灣身分證基本格式校驗（`^[A-Z][0-9]{9}$`），並將「最後確認送出」保留給本人或家屬，絕不自動送出掛號。

🔗 **家屬接力掛號：** 支援 LINE 官方分享 URL，可將去識別化（不含身分證）的掛號摘要傳送給家屬確認。

  ## 🚀 本機執行方式 (Local Setup)
本專案提供非常簡單的本機執行方式，即使沒有 AI 金鑰也能透過瀏覽器備援功能運行。

### 1. 系統需求
**Node.js** 22.13 或以上版本。

### 2. 安裝與啟動步驟
請在終端機中依序執行以下指令：
```bash
# 1. 安裝依賴套件
npm install

# 2. 複製環境變數設定檔
cp .env.example .env.local

# 3. 啟動開發伺服器
npm run dev
```

啟動後，請打開瀏覽器前往：http://localhost:3000。
 (若需建立正式上線版本，請執行 npm run build)

### 3. 環境變數設定 (選用)

打開剛剛複製的 .env.local 檔案，您可以填入 OpenAI 金鑰以啟用進階的 AI 語音與解析功能：

OPENAI_API_KEY=您的_OPENAI_API_金鑰
TRANSCRIPTION_MODEL=whisper-1
INTENT_MODEL=gpt-4o-mini

註：為了隱私與安全，金鑰僅放於本機或部署平台的 Secret 中，絕不會提交至 Git。所有語音錄音皆為即時處理，絕不寫入檔案或資料庫。

為了證明本專案的落地可行性與資料真實性，本專案的數據與素材來源皆為公開且具公信力之資料：

### 1. 醫療與數據來源

• 高齡化與數位落差數據： 儀表板數據取自國家發展委員會《中華民國人口推估報告》、TWNIC《台灣網路報告》及健保署統計年報。

• 示範聲明： 系統內顯示的醫師、日期、餘額皆為「穩定示範用的假資料（Mock Data）」，畫面上亦有明確標示為Demo，確保不干擾醫院真實運作。


### 2. 技術與開源工具

• 語音辨識與解析： 使用 OpenAI Whisper API 及 GPT-4o-mini。

• 前端與框架： 基於 Node.js 構建，具備響應式設計以支援長者手機大字體顯示。
